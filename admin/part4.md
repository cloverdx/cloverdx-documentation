# Wrangler and Data Manager administration

This section provides a detailed guide for managing and configuring CloverDX’s Wrangler and Data Manager components, focusing on user management, workspace control, and licensing to ensuring proper access control within an organization.

The [Wrangler administration](wrangler-administration.md) section covers the core aspects of managing [CloverDX Wrangler](../user/wrangler-index.md), including how to create and manage Wrangler users, configure and maintain Wrangler workspaces, and oversee the execution of Wrangler jobs. It also addresses important topics related to licensing, such as monitoring the number of allowed Wrangler seats, what to do when the Wrangler user limit is exceeded, and how to decrease the number of used seats when necessary. The section concludes with instructions on how to disable Wrangler entirely if required by the organization.

The [Data Manager](data-manager-administration.md) chapter provides an overview of how to configure the permissions on the Server to grant users the ability to use the Data Manager, how to monitor the resource usage and how the Data Manager is licensed.
