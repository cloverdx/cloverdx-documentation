### Configuration properties and sources

This section is a detailed guide to understanding and managing the various configuration options available within CloverDX. It focuses on how the platform can be customized to suit different environments, workflows, and performance requirements. The section provides insight into the configuration process, allowing users to optimize CloverDX for both development and production scenarios. Overall, this section is an essential resource for anyone tasked with configuring, optimizing, or extending CloverDX. Whether you are setting up a new environment, managing ongoing operations, or looking to push the platform’s capabilities further with custom plugins, this section provides the knowledge and tools needed to fully harness the power of CloverDX.

[Configuration sources](configuration-sources.md) outlines the different places where CloverDX configuration settings can be defined and how they interact. This chapter describes the [hierarchy of configurations](configuration-sources.md#priorities-of-configuration-sources), which is crucial for determining which settings take precedence when multiple sources are involved. By understanding this, users can better manage settings across different environments and ensure consistency in deployments.

[List of configuration properties](list-of-properties.md) is a comprehensive catalog of all available configuration properties within CloverDX. These properties control various aspects of system behavior. The list serves as a valuable reference for administrators who need to adjust the platform’s settings to meet specific technical requirements or to resolve issues. Each property is explained in detail, making it easier to understand its purpose and potential impact on the system.

[Example configuration file](example-configuration-file.md) provides a sample configuration that users can reference when setting up their own CloverDX environments. This example shows how the configuration properties can be organized within a file and offers a template that can be customized based on specific needs. By using this example, users can avoid common pitfalls in configuration and ensure that their CloverDX instances are set up correctly from the start.

[Engine configuration](server-engine-configuration.md) describes how to adjust the default internal engine properties.

[Extensibility - CloverDX engine plugins](pluginability-engine-plugins.md) explores how users can extend the functionality of the CloverDX platform by integrating external plugins.
