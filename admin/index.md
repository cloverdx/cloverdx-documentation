## Administration

This section is intended for administrators and technical staff who are responsible for the installation or configuration of CloverDX products. It provides comprehensive guidance on the platform’s various components, including the Designer, Server, Wrangler, and Data Manager.

- [**Designer installation**](part-installation-instructions.md): Instructions for installing and activating CloverDX Designer.
- [**Server installation**](server-install-index.md): Detailed guidance on installing CloverDX Server. This includes information on [system requirements](system-requirements-for-cloverdx-server.md), installation methods ([cloud deployments](server-in-cloud-marketplaces.md), [Docker/Kubernetes deployments](docker-install.md) or [manual installation](server-manual-install.md)), [system database configuration](examples-db-connection-configuration.md), [post-installation best practices](security-recommendations-for-server.md), or [configuration of Server cluster environment](cluster-setup-index.md#cluster-introduction).
- [**Upgrade**](part2.md): Upgrade steps for [CloverDX Designer](upgrading-cloverdx-designer.md) and steps for upgrading [CloverDX Server in cloud](common-marketplace-upgrade.md) or performing [manual upgrade](upgrading-server.md).
- [**Configuration**](part3.md): This section provides details on configuring [CloverDX Designer](designer-configuration.md) and [CloverDX Server](server-in-cloud-marketplaces.md#server-configuration), including introduction to [Server configuration properties and sources](server-config-prop-sources.md), [Server configuration migration](server-config.md), or [User management and access control](users-groups-index.md).
- [**Wrangler administration**](wrangler-administration.md): Information on configuring and managing CloverDX Wrangler.
- [**Data Manager administration**](data-manager-administration.md): Information on how to configure and manage Data Manager. Includes details about [user permissions](data-manager-administration.md#data-manager-permissions-in-cloverdx-server), [Data Manager set-up](data-manager-administration.md#data-manager-configuration) and more.
