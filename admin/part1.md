# Installation

Welcome to the **Installation section**, which provides detailed instructions for installing and initial configuration of our software. This section covers the installation of both the Designer and Server components, as well as the setup of Server clusters for advanced deployments.

In the [**Designer installation**](part-installation-instructions.md) section, you’ll find information on [system requirements](part-installation-instructions.md#system-requirements), followed by steps on [downloading](part-installation-instructions.md#downloading), [installing on different operating systems](part-installation-instructions.md#installing), and [activating the Designer](part-installation-instructions.md#activating-designer), as well as managing [licenses](part-installation-instructions.md#license-manager) and [troubleshooting common issues](part-installation-instructions.md#troubleshooting).

The [**Server installation**](server-install-index.md) section offers an overview of the [CloverDX Server architecture](architecture.md) and guides you through the essential steps for installation. It includes [system requirements](system-requirements-for-cloverdx-server.md), detailing both the hardware and software requirements needed for a successful installation and operation of the Server environment. The section also covers various deployment options, such as [Docker and Kubernetes](docker-install.md), [cloud](server-in-cloud-marketplaces.md), and [manual installation](server-manual-install.md). Additionally, it addresses [system database configuration](examples-db-connection-configuration.md), which is crucial for production deployments, and [post-installation best practices](security-recommendations-for-server.md) to ensure your Server is optimized and secured after installation.

The [**Server cluster setup and configuration**](cluster-setup-index.md) section focuses on creating a robust and scalable [Server cluster environment](cluster-setup-index.md#cluster-introduction). You’ll find key information on cluster setup, including configuring [mandatory](cluster-setup-index.md#mandatory-cluster-properties) and [optional properties](cluster-setup-index.md#optional-cluster-properties) or setting up [firewall exceptions](cluster-setup-index.md#firewall-exceptions). We provide examples for [different cluster sizes](cluster-setup-index.md#basic-2-node-cluster-configuration) and cover [troubleshooting common issues](cluster-setup-index.md#troubleshooting), such as connectivity problems and network malfunctions. Additionally, the section explains what [sandbox types](cluster-setup-index.md#sandboxes-in-cluster) can be used in cluster environments and introduces [remote edges](cluster-setup-index.md#remote-edges), which are used for data transfer between graphs running on different nodes.
