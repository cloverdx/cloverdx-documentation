### Manual installation

The **Manual installation** section guides you through the manual process of installing CloverDX Server, whether for [evaluation](evaluation-server.md) or [production](production-server.md) use. After installation, it covers essential [postinstallation configurations](postinstallation-configuration.md), such as [memory settings](postinstallation-configuration.md#memory-settings), code cache size, and firewall exceptions, to ensure optimal performance. You will also find instructions for configuring specific system parameters like the maximum number of open files and processes, reflective access, and setting up a reverse proxy. Additionally, [optional installation steps](optional-server-installation-steps.md) and [troubleshooting guidance](possible-installation-problems.md) are provided to address common issues and enhance the server’s functionality.
