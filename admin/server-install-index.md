## 2. Server installation

This section provides in-depth coverage of the [CloverDX Server architecture](architecture.md), including important information that will be crucial for understanding the principles of Server configuration later on. Before installing make sure to review the [system requirements](system-requirements-for-cloverdx-server.md), which are critical to understand before installation to ensure that the Server will function properly and perform optimally in your environment. You can choose how to install the Server based on your specific needs, with options for [Docker and Kubernetes](docker-install.md) deployments, [cloud deployments](server-in-cloud-marketplaces.md), or a [manual installation](server-manual-install.md). If performing manual installation, also follow the steps in [post-installation configuration](postinstallation-configuration.md) to ensure that your Server is properly configured for the environment on which it runs. For Production deployments, follow the steps in [system database configuration](examples-db-connection-configuration.md) to configure an external system database to store crucial information like job schedules, run history or user information. After installation, follow our [post-installation best practices](security-recommendations-for-server.md) to ensure that your environment is properly secured.
