#### Text manipulation steps

- [Trim](wrangler-step-trim.md): trim leading and trailing spaces
- [Substring](wrangler-step-substring.md): extract characters from a specified position in the text
- [Left substring](wrangler-step-left.md): extract characters from the beginning of the text
- [Right substring](wrangler-step-right.md): extract characters from the end of the text
- [Pad left](wrangler-step-pad-left.md): pad value to specified length by adding characters at the beginning
- [Pad right](wrangler-step-pad-right.md): pad value to specified length by adding characters at the end
- [Normalize whitespaces](wrangler-step-normalize-whitespaces.md): replace multiple whitespaces with single space
- [Remove whitespaces](wrangler-step-remove-whitespaces.md): remove all whitespace characters from text
- [Remove accents](wrangler-step-remove-accents.md): remove all accents from characters
- [Lowercase](wrangler-step-lowercase.md): convert letters in input text to lowercase
- [Propercase](wrangler-step-propercase.md): capitalize first letters in input text
- [Uppercase](wrangler-step-uppercase.md): convert letters in input text to uppercase
- [Remove non-alphanumeric characters](wrangler-step-remove-non-alphanumeric.md): remove non-alphanumeric characters from input text
- [Remove non-ASCII characters](wrangler-step-remove-non-ascii.md): remove non-ASCII characters from input text
- [Remove non-numeric characters](wrangler-step-remove-non-numeric.md): remove non-numeric characters from input text
- [Remove non-printable characters](wrangler-step-remove-non-printable.md): remove non-printable characters from input text
- [Replace text](wrangler-step-replace-text.md): replace matches of regular expression within text with another text
- [Calculate formula](wrangler-step-formula.md): use custom formulas to manipulate text
