#### Data set manipulation steps

- [Add column](wrangler-step-add-column.md): add new column to your data set.
- [Duplicate column](wrangler-step-duplicate-column.md): copy column into a new column.
- [Delete column(s)](wrangler-step-delete-column.md): remove column fro your data set.
- [Rename column](wrangler-step-rename-column.md): change name of a column.
- [Reorder columns](wrangler-step-reorder-columns.md): change the ordering of columns within the data set.
- [Merge columns](wrangler-step-merge-columns.md): merge values from multiple columns into a single column.
- [Split column](wrangler-step-split-column.md): split column based on a delimiter.
- [Filter rows based on formula](wrangler-step-filter-with-formula.md): keep or remove rows based on result of a formula.
- [Sort](wrangler-step-sort.md): sort data based on selected key columns.
- [Group by](wrangler-step-group-by.md): group rows and calculate summary values.
- [Deduplicate](wrangler-step-deduplicate.md): remove duplicate rows based on selected key columns.
- [Lookup](wrangler-step-lookup.md): merge your dataset with another based on key columns.
- [Calculate formula](wrangler-step-formula.md): calculate formula and write result to selected column.
