- [Sequence](wrangler-step-sequence.md): generate numeric sequences
- [Absolute value](wrangler-step-absolute.md): calculate absolute value of a number
- [Square root](wrangler-step-square-root.md): calculate the square root of a number
- [Exponential](wrangler-step-exponential.md): calculate exponential of a number
- [Power](wrangler-step-power.md): raise a number to a power
- [Natural logarithm](wrangler-step-natural-log.md): calculate natural logarithm of a number
- [Common logarithm](wrangler-step-common-log.md): calculate common logarithm of a number
- [Division remainder](wrangler-step-division-remainder.md): calculate remainder of value divided by a number
- [Calculate formula](wrangler-step-formula.md): compute complex expressions using custom formulas
