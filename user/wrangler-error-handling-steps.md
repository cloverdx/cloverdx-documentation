#### Error handling steps

- [Remove rows with errors](wrangler-step-remove-rows-with-errors.md): remove rows that contain errors in selected columns
- [Replace errors](wrangler-step-replace-errors.md): replace cells which contain errors with provided value or formula calculation result
- [Clear error cells](wrangler-step-clear-error-cells.md): clear cells that contain errors (set their value to *null*)
- [Replace empty values](wrangler-step-replace-empty.md): replace empty values in column with provided value
- [Fill down](wrangler-step-fill-down.md): replace empty values with previous non-empty values
- [Calculate formula](wrangler-step-formula.md): fix errors in your data using custom formulas
