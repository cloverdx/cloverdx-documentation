## Development

This section is intended for developers and technical staff responsible for creating and managing data transformation workflows. It provides comprehensive guidance on the platform’s development tools and processes. Key topics addressed in this section include:

- [**First steps with CloverDX Designer**](part-tutorial.md): A tutorial, which will guide you step-by-step through your first graph creation.
- [**CloverDX AI Assistant**](designer-ai-assistant.md): An overview of CloverDX AI Assistant including [Quick start guide](designer-ai-assistant.md#ai-assistant-quick-start) and more to help you understand how the Assistant works.
- [**Designer user interface**](part1.md): An overview of the CloverDX Designer interface, including [its layout](designer-layout.md), [keyboard shortcuts](keyboard-shortcuts.md), and [common dialogs](common-dialogs.md).
- [**Projects**](part2.md): Information on [project types](cloverdx-projects-type.md), how to [work with server projects](server-projects-usage.md), or how to [export project as library](export-library.md).
- [**Job types**](part3.md): Introduction to job types available in CloverDX - learn about [graphs](part-graph-elements-structures-tools.md), [subgraphs](subgraphs.md), [jobflows](part-jobflow.md), and [Data Services](data-service.md).
- [**Job elements**](part4.md): Job elements are the fundamental building blocks of data transformation workflows in CloverDX. They represent various components and connections that work together to process and manipulate data: [components](components.md), [edges](edge.md), [metadata](metadata.md), [connections](connections.md), [parameters](parameters.md), [sequences](sequences.md), [lookup tables](lookup-tables.md), [notes](note.md), the [dictionary](dictionary.md), and [execution properties](jobconfig.md).
- [**CTL2 language**](part5.md): A comprehensive reference for the CTL2 language, which is used to define and control data transformations within CloverDX workflows.
- [**Component reference**](part6.md): List of available components along with their descriptions.
- [**Advanced**](part7.md): This section includes recommendations for advanced topics like [library development](libraries-dev.md) or [data partitioning](parallel-running.md).
