## 45. Deprecated

**Deprecated** category contains components that have been replaced by other new components. We do not recommend using deprecated components in newly created graphs.

The **deprecated** components were originally placed in different categories (readers, writers, etc.).

- [ApproximativeJoin](aproxmergejoin.md)
- [InfobrightBulkWriter](infobrightdatawriter.md) loads data into an Infobright database using the Infobright client.
- [JavaExecute](javaexecute.md)
- [MongoDBExecute](mongodbexecute.md) executes JavaScript code on the **MongoDB** database.
- [RunGraph](rungraph.md) runs specified **CloverDX** graph(s).
- [SystemExecute](sysexecute.md) executes system commands.
- [TableauWriter](tableauwriter.md) writes data in Tableau (`.hyper`) files.
