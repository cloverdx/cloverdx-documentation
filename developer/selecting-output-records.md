#### Selecting output records

**Writers** let you limit the records that should be written. You can limit the number of records to be written and skip the specified number of records. If you need to apply a filter on output records, use [Filter](extfilter.md) before the Writer.

The limit on the number of written records is set up with **Max number of records**.

The number of records to be skipped is set up with **Number of skipped records**.

The following components let you set up **Max number of records** or **Number of skipped records**:

| [SpreadsheetDataWriter](spreadsheetwriter.md) |
| [StructuredDataWriter](structurewriter.md) |
| [X12Writer](x12writer.md) |
| [XMLWriter](extxmlwriter.md) (**Number of skipped records only**) |
