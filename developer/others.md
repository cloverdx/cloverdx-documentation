## 44. Others

| [Common Properties of Others](common-of-others.md) |
| --- |

Some of the components are slightly different from those previously described. We call this group of components: **Others**.

**Others** serve to perform multiple and heterogeneous tasks.

As **Others** are heterogeneous group of components, they have no common properties.

- [CheckForeignKey](checkforeignkey.md) checks foreign key values and replaces those invalid by default values.
- [CustomJavaComponent](genericcomponent.md) executes user-defined java transformation.
- [DBExecute](dbexecute.md) executes SQL/DML/DDL statements against database.
- [HTTPConnector](httpconnector.html) sends HTTP requests and receives responses from web server.
- [LookupTableReaderWriter](lookuptablereaderwriter.md) reads data from a lookup table and/or writes data to a lookup table.
- [RESTConnector](restconnector.md) simplifies the integration of RESTful APIs into data processing workflows by pre-loading settings from OpenAPI documentation.
- [SequenceChecker](sequencechecker.md) checks whether input data records are sorted.
- [WebServiceClient](webserviceclient.md) calls a web-service and maps response to output ports.
